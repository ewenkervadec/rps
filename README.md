# Risques psychosociaux chez les étudiants en médecine

Support projeté du cours de DFGSM2. Tout tient dans un seul fichier, `index.html`, sans dépendance externe : il fonctionne aussi hors ligne.

## Pendant le cours

| Touche | Action |
| --- | --- |
| → ou Espace | Étape ou diapo suivante |
| ← | Étape ou diapo précédente |
| 12 puis Entrée | Aller à la diapo 12 |
| O | Vue d'ensemble |
| N | Notes |
| B | Écran noir |
| T | Thème clair ou sombre |
| F | Plein écran |
| G | Guide de l'enseignant (mot de passe) |
| ? | Aide |

Vue présentateur : ajoutez `#presentateur` à la fin de l'adresse, puis ouvrez l'adresse normale dans une seconde fenêtre placée sur le projecteur. Les deux fenêtres restent synchronisées.
